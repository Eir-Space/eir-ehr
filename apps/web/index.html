An open EHR, built together

Explore the repository

Swedish healthcare needs software that people can inspect, improve and adapt. Eir is an independent, open collaboration to build that foundation: useful clinical workflows, replaceable modules, modern APIs and AI that remains subject to clinical review.

This is an early working implementation, not a finished or certified clinical product. We publish the source, limitations and delivery plan so contributors can see exactly what works and what still needs to be built.

Contribute code

Fork the repository, choose a focused change, add tests and open a pull request. New modules should declare their contracts, permissions and failure behavior.

How to open a pull request

Bring clinical experience

Tell us where the workflow fails: consultations, handovers, consent, proxy access and accessibility. Use fictional examples, never patient information.

Suggest a workflow or report a problem

Help the project grow

Improve documentation, review the design, test a country pack, or help specify Swedish integrations. Working adapters and careful validation matter more than feature lists.

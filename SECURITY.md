# Security

This repository is a development EHR and must currently use synthetic data. Report vulnerabilities through the repository's private security advisory channel if enabled. Otherwise contact the Eir Space repository maintainers to arrange private reporting; do not put health data or credentials in a public issue.

Include the affected commit, reproduction with synthetic data, and impact. The active development branch is the supported version. There is no production security or incident-response SLA in this release.

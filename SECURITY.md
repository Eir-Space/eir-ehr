# Security

This repository is a development EHR and must currently use synthetic data. Use [private vulnerability reporting](https://github.com/Eir-Space/eir-ehr/security/advisories/new), which is enabled for this repository. Do not put health data or credentials in a public issue.

Include the affected commit, reproduction with synthetic data, and impact. The active development branch is the supported version. There is no production security or incident-response SLA in this release.
